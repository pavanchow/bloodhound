The controls

  • Continue ▶ runs forward until the next breakpoint, or to the end.
  • Next (over) advances to the next source line in the current function. If the line calls a function, the whole call runs and you stop after it returns.
  • Step into advances to the next source line, descending into any function that gets called.
  • Step out runs until the current function returns, landing in the caller.
  • Step executes exactly one VM instruction.
  • ◀ Back is the reverse step. It moves one instruction backward in time and restores the exact earlier state.
  • The timeline scrubber jumps to any executed step instantly. Drag it left to travel into the past and right to return.

Reading the views

  • The highlighted source line is the line about to execute. The step counter (top right) shows how far into the run you are.
  • The call stack lists active frames, innermost last, with each frame's locals.
  • The value stack, locals, globals, and memory show live state. Any cell that changed on the current step is highlighted green, so time travel is legible: step back and the green shows what un-happened.
  • Pick a global and press Toggle watch to mark it with an eye. When a watched value changes, the panel reports the step and the old and new values.

A short guided tour

  1. Leave sum_loop selected. Click the source line sum += i to set a breakpoint (its gutter turns red).
  2. Press Continue a few times and watch global[0] climb 1, 3, 6, 10, 15 as the loop runs.
  3. Set the watch index to 0 and press Toggle watch. Continue once more and read the reported old to new change.
  4. Now press ◀ Back several times. The sum counts back down. The print in the output un-happens. That is reverse execution.
  5. Drag the timeline to the far left, then to the far right, to leap across the whole run.
  6. Switch to factorial and use Continue to a breakpoint inside recurse, then read the deep call stack.
